# Multi-Factor Authentication (MFA)

MFA adds an additional verification step beyond a password.

- Examples: authenticator app, hardware key, SMS code (less secure than app/hardware).
- Even if a password is guessed or leaked, MFA can prevent unauthorized access.
- MFA is especially important for email, financial, and primary accounts.

Recommendation: Enable MFA where available, even with strong passwords.
