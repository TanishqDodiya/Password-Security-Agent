# Password Attacks

Common attack methods against passwords:

- **Brute-force**: systematically trying all possible combinations. Longer, diverse passwords increase time required.
- **Dictionary attacks**: trying common words, names, and leaked passwords. Predictable words and patterns are vulnerable.
- **Credential stuffing**: reusing leaked username/password pairs across sites. If one site is breached, reused passwords on other sites are compromised.
- **Rainbow tables**: precomputed hashes for common passwords; salting and uniqueness help mitigate.

No password can be guaranteed uncrackable; the goal is to increase effort required.

Defense: Use unique, diverse, non-sequential passwords per site and avoid reused patterns.
