# Password Length

Longer passwords increase the search space for brute-force attacks.

- Each additional character multiplies the number of possible combinations.
- A password with 8 characters is significantly harder to brute-force than one with 6, assuming similar character sets.
- Length alone does not guarantee security if the password is predictable (e.g., repeated characters or sequential patterns).
- Character diversity (mix of types) combined with length provides better resistance than length alone.

Recommendation: Use at least 12 characters where possible, and combine length with diverse character types.
