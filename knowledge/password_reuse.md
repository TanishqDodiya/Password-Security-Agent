# Password Reuse

Reusing the same password across multiple accounts is risky.

- If one service is breached, attackers try the same password on other services (credential stuffing).
- Unique passwords per service limit the impact of a single breach.
- Even strong passwords become high-risk if reused.

Recommendation: Use a unique password for each account. A password manager can help generate and store them.
