              Password Entropy

              Shannon entropy measures character distribution: -Σ p·log2(p). Estimated entropy assumes random generation from charset (length × log2(charset)). High entropy indicates larger theoretical search space, but does not guarantee security if the password contains common patterns or words.

              Source: knowledge/password_length.md — longer passwords increase brute-force search space, but length alone is insufficient if predictable.

              Brute-force Search Space

              Search space is charset_size ^ length (displayed as 2^log2). Example: 62-char set (a-zA-Z0-9) with length 12 ≈ 2^71 combinations. This assumes random generation; predictable patterns drastically reduce effective resistance. Avoid false precision.

              Source: knowledge/password_length.md

              Dictionary & Common-password Attacks

              Local dataset top 500 and a small common-word list are checked. If a password equals or contains a common word (e.g., “password”, “admin”), it is flagged as common_password / dictionary_word. This is a local common-password check, not a breach lookup — we do not claim the password is breached.

              Sources: knowledge/common_patterns.md, knowledge/password_attacks.md

              Keyboard & Sequential Patterns

              Detects qwerty, asdf, zxcv, 1234, sequential digits/letters (123, abc), repeated blocks (abab), and runs like aaaa. These are common walks attackers try first.

              Source: knowledge/common_patterns.md

              Predictable Substitutions & Years

              Leet substitutions (a→@, s→$) are flagged but not treated as strong protection. Year patterns (19xx/20xx) and date-like structures are flagged as predictable.

              Sources: knowledge/common_patterns.md, knowledge/password_attacks.md

              Character Diversity & Credential Stuffing

              Diversity = unique / length. Low diversity with length indicates repetition. Credential stuffing risk cannot be determined from this password alone; reuse across services increases it. Use unique passwords per service.

              Sources: knowledge/common_patterns.md, knowledge/password_reuse.md — “Credential stuffing exposure cannot be determined from this password alone; password reuse across services increases this risk.”

              Entropy vs Guessability

              Mathematical entropy (randomness) differs from real-world guessability. A long password like password123456 has high theoretical entropy but low guessability due to dictionary + sequential patterns. The agent prioritizes guessability signals over entropy alone.

              Source: knowledge/password_length.md + common_patterns.md
